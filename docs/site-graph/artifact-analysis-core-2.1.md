# Artifact Analysis Core 2.1

The artifact adapter extracts deterministic evidence from explicitly selected
generated output without executing the target project.

Supported evidence:

- generated HTML routes, titles, first H1, canonical URL, robots indexability,
  JSON-LD type names, anchors, and form/button targets;
- `sitemap.xml` and bounded XML sitemap documents;
- common route and build manifests, using only allowlisted route-bearing fields;
- `_redirects` declarations;
- ZIP and tar-family archives under the same limits as directories;
- owner-supplied read-only deployment JSON normalized by the deployment metadata
  parser.

The lane-local `ArtifactAdapterResult` includes exact file hashes, parser
version, supplied revision, route and link evidence, revision state, diagnostics,
resource-limit coverage, and an aggregate deterministic evidence hash. It is
serializable with `as_dict()` for conversion to the shared Graph Evidence Core
contract during reconciliation.

Revision association is explicit. Files are associated with the caller-supplied
revision, while manifest or deployment claims are independently classified.
`mismatched`, `conflicting`, and `unchecked` are retained rather than converted
to a false match.

During serial reconciliation, lane-local `matched` maps to the shared `exact`
revision relation. `mismatched` and `conflicting` map to shared `mismatch` and
must block evidence publication until the revisions are reconciled. `unchecked`
maps to shared `unchecked`; it must not be silently upgraded. Artifact routes
map to page candidates/entities and distinct source locations preserve duplicate
link occurrences.

## Coverage and limitations

Coverage reports input entries, supported files and bytes, evidence type counts,
JSON nodes, routes, links, and active resource ceilings. It also records that
local build execution and provider mutation are disabled.

Artifact evidence is not source evidence or browser evidence. It cannot prove
how generated bytes arose, observe JavaScript-created DOM state, authenticated
views, responsive visibility, console failures, or interaction-only links.
Those questions remain for source, rendered-crawl, and reconciliation lanes.
